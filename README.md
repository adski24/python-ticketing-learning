# Python Ticketing System Learning Journey

## Goal

Learn Python by gradually building the skills needed to create a Shopify-connected ticketing system.

The final system will eventually be able to:

- receive ticket orders
- create unique ticket IDs
- store tickets in a database
- generate QR codes
- email tickets to customers
- scan and validate tickets
- prevent duplicate entry
- connect to Shopify
- run online securely

## Learning Rule

For each topic:

1. Learn the concept.
2. Write a small example.
3. Complete exercises without copying a solution.
4. Build the mini-project.
5. Commit the finished work to Git.
6. Write down what was difficult and what was learned.

The goal is not just to make the program work. The goal is to understand why it works.
